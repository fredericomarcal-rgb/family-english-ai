# Family English AI (v3.0)

Aplicativo mobile-first (PWA) de aprendizado de inglês com IA Gemini para toda a família.

## Como publicar gratuitamente na Vercel (sem precisar instalar programas)

1. Descompacte este arquivo ZIP em uma pasta no seu computador.
2. Crie uma conta gratuita em **github.com**, clique em **New repository** (ex: `family-english-ai`) e clique em **uploading an existing file**.
3. Arraste todos os arquivos de dentro da pasta descompactada para o GitHub e clique em **Commit changes**.
4. Acesse **vercel.com**, entre com sua conta do GitHub, clique em **Add New > Project**, selecione `family-english-ai` e clique em **Deploy**.
5. Em menos de 1 minuto você receberá o link oficial (ex: `family-english-ai.vercel.app`) para enviar no WhatsApp da família!
